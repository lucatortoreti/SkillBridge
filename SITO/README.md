## Detalles técnicos

HTML y CSS estáticos, sin dependencias ni proceso de compilación. Un solo archivo `index.html`
más los recursos de `assets/`. Funciona en tema claro y oscuro, es responsive desde 375 px y se
publica con GitHub Pages.

Para verlo en local basta abrir `index.html` en el navegador.
